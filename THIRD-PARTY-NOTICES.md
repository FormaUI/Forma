# Third-party notices

A Forma package that embeds work from another project carries the notice for it beside its own
README, so the notice ships inside that package and credits nothing another package ships:

- [`Forma.AddOns.Emojis.Twemoji`](src/AddOns/Forma.AddOns.Emojis.Twemoji/THIRD-PARTY-NOTICES.md) — Twemoji artwork and Unicode CLDR annotations
- [`Forma.Framework.Currencies`](src/Framework/Forma.Framework.Currencies/THIRD-PARTY-NOTICES.md) — Unicode CLDR currency data
- [`Forma.Framework.Icons.Glyphs`](src/Framework/Forma.Framework.Icons.Glyphs/THIRD-PARTY-NOTICES.md) — Bootstrap Icons brand marks
- [`Forma.Framework.Localization`](src/Framework/Forma.Framework.Localization/THIRD-PARTY-NOTICES.md) — Unicode CLDR plural rules
