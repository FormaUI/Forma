# Third-party notices

Forma's packages embed work from the projects below. Each notice is reproduced here because
that content ships inside a package rather than being fetched at run time.

## Twemoji

The emoji sprite sheets `2Site.Forma.UI.Features.Emojis.Twemoji` ships are built from
[Twemoji](https://github.com/jdecked/twemoji) artwork, regenerated by `scripts/Get-TwemojiPack.ps1`.

The graphics are copyright 2020 Twitter, Inc and other contributors, and copyright 2023 the
Twemoji contributors, used under the
[Creative Commons Attribution 4.0 International license (CC-BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
The artwork is repackaged into sprite sheets; the individual images are otherwise unmodified.

## Unicode CLDR

The emoji names and search keywords in that same package come from the
