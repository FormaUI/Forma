# Third-party notices

`Forma.Framework.Localization` embeds work from the project below. The notice is reproduced here
because that content ships inside the package rather than being fetched at run time.

## Unicode CLDR

The plural rules compiled into this package, the categories each language distinguishes and the
conditions that select them, come from [Unicode CLDR](https://cldr.unicode.org), release 48, generated
by `scripts/Update-PluralRules.ps1` and used under the
[Unicode License](https://www.unicode.org/license.txt).
