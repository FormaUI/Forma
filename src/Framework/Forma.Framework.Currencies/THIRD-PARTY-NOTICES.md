# Third-party notices

`Forma.Framework.Currencies` embeds work from the project below. The notice is reproduced here
because that content ships inside the package rather than being fetched at run time.

## Unicode CLDR

The currency codes, their minor units, the locales and their parents, and the currency symbols
compiled into the asset this package embeds come from [Unicode CLDR](https://cldr.unicode.org),
fetched by `scripts/Update-CurrencyData.ps1` and used under the
